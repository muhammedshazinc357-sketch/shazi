CLASSIC SNAKE — HTML, CSS & JavaScript

FILES
- index.html: page structure and game interface
- styles.css: responsive visual styling
- script.js: Snake gameplay and controls

RUN
1. Extract the ZIP.
2. Open index.html in a modern browser. No server or build tools are needed.

CONTROLS
- Arrow keys or WASD: steer
- Space: start / pause / resume
- On touchscreens: swipe on the board or use the direction pad
- Restart button: begin a new round

Features: score and saved best score, increasing speed, pause/resume, collision detection, game-over and restart.
