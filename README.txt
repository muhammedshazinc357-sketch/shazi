SNAKE GAMES — HTML, CSS & JAVASCRIPT

Files
-----
index.html   Main game page
styles.css   Layout, responsive styling, and visual design
script.js    Snake movement, collision detection, scoring, sound, and controls

How to play locally
-------------------
1. Extract snake-games.zip.
2. Keep index.html, styles.css, and script.js in the same folder.
3. Open index.html in a modern web browser.
4. Click START GAME.

Controls
--------
- Arrow keys or WASD: steer the snake
- Space: pause/resume
- Touch directional pad: mobile controls
- Choose Chill, Classic, or Fast to change game speed
- Best score is saved in local browser storage when available

Hosting
-------
Upload index.html, styles.css, and script.js to the public folder of your web host.
For a typical static hosting setup, this may be called public_html, www, or htdocs.
Make sure the files are in the same directory and that index.html is the entry page.

The Google Fonts import is optional; the game works with fallback fonts if unavailable.
